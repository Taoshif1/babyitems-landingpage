# সহজশপ ক্লায়েন্ট ডেমো

এটি একটি সম্পূর্ণ স্ট্যাটিক Bangla COD landing-page demo। কোনো বাস্তব অর্ডার, কুরিয়ার বুকিং, পেমেন্ট বা authentication নেই।

## চালানো

`index.html` সরাসরি ব্রাউজারে খুলুন। অ্যাডমিন ডেমো: `admin.html`

**ডেমো লগইন:** `admin` / `admin123`

## নোট

- স্থানীয় ছবি বা ভিডিও ফাইল পাওয়া যায়নি, তাই বিদ্যমান remote demo imagery রাখা হয়েছে।
- ভিডিও অংশটি ইচ্ছাকৃতভাবে preview-only; প্রকৃত ভিডিও এলে HTML5 `<video controls playsinline preload="metadata">` বসানো যাবে।
- প্রকৃত ব্যবহারের আগে server-side order validation, secure authentication, real contact information, image hosting এবং CSP যোগ করতে হবে।
